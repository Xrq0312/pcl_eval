# 传统几何特征实验线：阶段 F0/F1

更新时间：2026-11-20
分支：`codex/geometric-feature-lab`

## 1. 范围与实验口径

本实验线与 `primitive_core` 隔离：`geometric_features` 不链接生产检测库，
`geometry_feature_probe` 也不调用现有候选生成、区域生长、模型选择或合并逻辑。
原算法因此仍是未修改基线。

当前有两类实验：

1. 合成扰动：已知曲面、参数和定向法向，控制采样数、球冠/圆柱圆弧覆盖、
   圆柱长度、位置噪声、法向噪声和法向符号翻转。
2. `oracle_instance_patch`：用数据集 GT 实例标签切出正确曲面块，再估计法向并计算
   特征。它测量“特征及参数初值在正确分块上的上限”，**不是**检测实例召回、IoU
   或完整流水线精度。

GCCao 两个公开 PLY 没有独立逐点实例/参数 GT。作者保存的 MAT 是算法输出，不能在
本实验中充当真值；因此目前只允许无标签特征分布或定性检测复核，不报告本模块的
分类准确率和参数误差。

## 2. 已实现特征

### 2.1 法向补偿低秩

令定向单位法向为 `n_i`，定义

```text
q_i(R) = p_i - R n_i
```

理想情形：

- 球面：`p_i = c + R n_i`，所以所有 `q_i=c`，中心化协方差秩为 0；
- 圆柱：`p_i = a + t_i u + R n_i`，所以 `q_i` 落在轴线上，秩为 1；
- 平面：法向恒定，补偿只是平移，位置协方差仍为秩 2；平面的 `R` 没有几何意义。

球面半径初值通过最小化中心化补偿点总方差得到闭式解。记
`P_i=p_i-mean(p)`、`N_i=n_i-mean(n)`：

```text
R* = sum(P_i dot N_i) / sum(||N_i||^2)
c* = mean(p) - R* mean(n)
```

圆柱以法向协方差最小特征向量初始化轴 `u`，在横截面投影
`T=I-u u^T` 中解同一个一维二次问题，再用补偿点协方差最大特征向量更新轴。
短轴向跨度下，仅在补偿谱存在足够大的主特征值间隔时接受轴更新。

这个推导只证明理想定向法向下的代数性质，不证明扫描数据上的统计可靠性。主要
失效机制为：

- 单点法向翻转会产生约 `2R` 的补偿误差；
- 法向角误差 `delta` 产生约 `R*delta` 的横向误差，大半径曲面反而更敏感；
- 短圆弧/小球冠使半径、中心或轴线病态；
- GT 实例点本身可能因深度噪声、遮挡和标签边缘而不落在理想曲面上；
- 球的补偿点秩 0 同时也满足“秩不超过 1”，所以圆柱残差不能单独区分球面；
- 很短的圆柱在球面补偿目标下也可能出现较低残差。

### 2.2 点对不变量

模块累计定向点对的 `dp=p_j-p_i`、`dn=n_j-n_i`。理想球满足
`dp=R dn`；理想圆柱在估计轴的横截面满足 `T dp=R T dn`。当前实现输出球/圆柱
点对半径和相对残差，并限制最多 4096 对，作为无需预分区候选投票的前置验证。
其思想与 Drost 等人的 oriented point-pair representation 一致，但当前代码没有复制
其物体识别投票器。

### 2.3 Shape Operator

实现了两个明确区分的版本：

- `normal-LS shape operator`：法向差对切平面坐标做对称线性最小二乘。它是便宜
  对照，不是 ASO；在整个大实例上使用会违反局部微分假设。
- `ASO`：直接纳入 Lejemble、Coeurjolly、Barthe、Mellado 的 MIT 单头文件作者
  实现。ASO 对 APSS 加权代数球的核函数求导得到 Hessian 和形状算子。当前接口在
  一个查询点和紧支撑半径上返回主曲率/主方向。

精确单测覆盖任意中心球和任意轴圆柱；球的两个曲率、圆柱的一个非零曲率和一个
零曲率均通过容差检查。

来源：

- ASO 论文：https://doi.org/10.1111/cgf.14368
- 作者实现：https://github.com/STORM-IRIT/algebraic-shape-operator
- Point Pair Features：https://doi.org/10.1109/CVPR.2010.5540108
- Efficient RANSAC：https://doi.org/10.1111/j.1467-8659.2007.01016.x
- SED-Net 边界监督参考：https://github.com/yuanqili78/SED-Net

## 3. 合成实验

命令：

```powershell
cmake --preset windows-vcpkg
cmake --build --preset release
ctest --preset release
.\build-native\Release\geometry_feature_synthetic.exe `
  --output results\features\low_rank_synthetic.csv
```

矩阵共 652 行：640 个噪声/覆盖/密度/长度组合，另有 12 个法向符号翻转反例。
位置噪声最大 `1%R`，法向高斯角噪声最大 `5 deg`，点数为 256/1024；球冠覆盖
20/45/90/180 度，圆柱圆弧覆盖 15/30/60/120/360 度，长度为 0.2/1/4 倍半径。

理论性质得到验证：无噪声且法向正确时，所有覆盖范围内球的球心/半径和圆柱的
半径/轴均恢复到数值精度，包括 15 度短圆弧。但这只是可辨识模型的无噪声结果。

完整球面、1024 点的代表性结果：

| 位置噪声 | 法向噪声 | 半径绝对误差/R | 球心误差/R | q 归一化 RMSE |
|---:|---:|---:|---:|---:|
| 0 | 1 deg | 0.015% | 0.041% | 1.75% |
| 0 | 5 deg | 0.374% | 0.177% | 8.64% |
| 1%R | 0 | 0.042% | 0.058% | 1.73% |
| 1%R | 5 deg | 0.356% | 0.239% | 8.94% |

完整圆柱、长度 `1R`、1024 点的代表性结果：

| 位置噪声 | 法向噪声 | 半径绝对误差/R | 轴角误差 | 轴偏移/R | q 归一化 RMSE |
|---:|---:|---:|---:|---:|---:|
| 0 | 1 deg | 0.0001% | 0.032 deg | 0.033% | 1.13% |
| 0 | 5 deg | 0.035% | 0.482 deg | 0.043% | 6.29% |
| 1%R | 0 | 0.016% | 0.049 deg | 0.057% | 1.34% |
| 1%R | 5 deg | 0.019% | 0.377 deg | 0.247% | 6.31% |

法向符号是硬前提：仅 1% 随机翻转时，球半径误差已为 2.7%，圆柱半径误差为
2.6%；5% 翻转时分别增至 11.7% 和 9.3%。因此低秩补偿前必须有局部一致定向，且
不能用“对齐到全局平均法向”处理闭合球/圆柱。

探索性阈值在同一合成矩阵上的分类消融（这是同域拟合结果，不是留出泛化）：

| 特征 | 准确率 |
|---|---:|
| 点对法向变化 + 球点对残差 | 88.75% |
| 单查询点 ASO | 87.03% |
| ASO + 点对残差 | 96.56% |

核心特征（不含法向估计）平均 1.08 ms/块；单查询点 ASO 平均 0.041 ms。硬件和
编译配置为本机 Release 构建，这些耗时只用于同机相对比较。

## 4. 真实数据 oracle-instance 结果

固定配置：每实例最多 2048 点，PCL PCA kNN 法向 `k=64`，按局部
`|n_i dot n_j|` 最大优先生成森林传播符号；ASO 使用查询点第 64 邻居距离为半径。
分类阈值只在合成矩阵选择后冻结，没有在下表数据上重调。

| 数据 | 实例数 | 点对 | ASO | 组合 | 法向+特征+ASO平均耗时/实例 |
|---|---:|---:|---:|---:|---:|
| SHREC2022 test 子集 | 30 | 80.0% | 60.0% | 60.0% | 12.2 ms |
| Fit4CAD 12 scenes | 177 | 93.8% | 92.7% | 94.4% | 5.9 ms |
| BAGSFit 10 frames | 102 | 38.2% | 38.2% | 39.2% | 11.1 ms |

组合在合成数据上的增益没有迁移到 SHREC，说明固定 ASO 尺度和阈值存在明显
数据域依赖；不得用合成 96.56% 作为集成依据。

“可靠初值”定义：球半径误差 `<5%` 且球心误差 `<0.1R`；圆柱半径误差 `<5%`、
轴角 `<2 deg` 且轴偏移 `<0.1R`。

| 数据 | 球：估计法向 | 球：oracle 法向 | 圆柱：估计法向 | 圆柱：oracle 法向 |
|---|---:|---:|---:|---:|
| SHREC2022 | 7/10 | 10/10 | 8/10 | 10/10 |
| Fit4CAD | 2/2 | 2/2 | 41/68 | 68/68 |
| BAGSFit | 7/19 | 13/19 | 7/31 | 20/31 |

这里的 oracle 法向由 GT 参数和观测点构造。BAGSFit 即使使用 oracle 法向仍只有
约 65--68% 达标，证明失败不全是法向估计造成的；短小实例、深度噪声、遮挡边缘
和观测点偏离理想曲面都会破坏初值。

多尺度初测也否定了单一 `k`：BAGSFit 球可靠率从 `k=16` 的 5.3% 上升到
`k=192` 的 47.4%，但圆柱可靠率同时从 35.5% 降到 6.5%。球需要更强平滑，短圆柱
需要保留局部法向变化。类型未知时必须联合比较多个尺度，不能先固定一个全局 k。

## 5. 当前结论与集成门槛

### 可以继续推进

1. 把低秩结果作为**候选参数初值**，交给现有几何距离/法向/支持度验证；不直接
   输出模型类型或实例。
2. 球使用较粗尺度、圆柱同时保留细尺度轴候选；在模型选择阶段竞争，而不是提前
   用一个尺度硬分类。
3. 用点对关系生成不依赖区域生长的球/圆柱候选。短圆弧必须有条件数、半径范围、
   补偿谱间隔和独立点集复验。
4. ASO 作为局部软特征：使用主曲率比和跨尺度稳定性，不使用当前固定阈值硬门控。

### 暂不集成

1. 法向补偿低秩不能作为独立分类器；BAGSFit 的失败率过高。
2. 单尺度 ASO/normal-LS 不能替换现有区域或模型验证。
3. 不能从 `q` 的圆柱残差小直接判圆柱，因为球面同样满足秩不超过 1。
4. 当前还没有实例召回/IoU 增益证据，生产流水线保持不变。

## 6. 下一阶段 F2（尚未宣称完成）

1. 多尺度局部 ASO：按点间距构造 32/64/128/256 邻域，记录主曲率的偏差、方差和
   尺度稳定区间；将运行时间按查询点数外推到整云。
2. 曲率感知边界：比较观测法向变化与 `Delta n ~= -S Delta p_t` 的预测残差；在
   同一曲面内部、真实交线、遮挡边和噪声边分别统计 ROC，而非直接改区域生长。
3. 点对候选投票：在未分割整云上做半径/球心/轴方向桶投票，并与现有全局候选做
   proposal recall、候选数和耗时消融。
4. 将通过离线门槛的单一特征以实验开关接入候选池；重新跑完整检测实例召回、IoU、
   参数误差和耗时。只有真实数据留出集有稳定增益才更改默认路径。
