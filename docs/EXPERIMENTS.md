# Native staged-ablation log

All numbers below are generated by `tools/run_native_ablation.py` with fixed
seed 1337. Generated predictions stay under ignored `results/`; the runner,
configuration and aggregate table are versioned.

## BAGSFit organized noisy subset (10 samples)

Configuration: `distance=0.02 m`, `min_points=80`, optional 640x480
`pixel_map.txt`, first ten sorted samples in `samples/bagsfit_v28`. The fitter
does not read GT. The distance matches the pre-existing repository evaluation
default. A stricter 0.006 m diagnostic was retained locally and failed because
the analytic-GT residual median itself reaches 0.021 m on the largest noisy
plane.

| cylinder axis error, degrees* | 0.527 | 0.584 |
| cylinder axis-line distance, m* | 0.00268 | 0.00376 |
| cylinder radius absolute error, m* | 0.00263 | 0.00339 |
| cylinder radius relative error* | 0.0165 | 0.0174 |

`*` Parameter-error means are computed only over typed cylinder detections;
the conditioning set therefore differs between stages. Stage 2 detects more
cylinders but does not yet improve their conditional parameter error. This is
the explicit target for the GCCao-style high-precision refit/validation stage.

Stage 1's final connectivity heuristic is both inaccurate and expensive on
nonuniform range data (individual samples reached 72.8 s). Stage 2 omits that
heuristic pending a separately ablated boundary-aware stage, which explains
part of its runtime reduction. These results are an improvement over the new
independent Stage 1 implementation, not over the unavailable original C++
algorithm described in the upstream reports.

## Synthetic regression

The native unit test contains two disconnected coplanar planes, a sphere and
a cylinder. It requires deterministic fixed-seed output, more than 90% point
coverage, detection of all three primitive types, and separation of the two
coplanar instances. The frozen upstream prediction remains evaluated
separately as documented in `SOURCE_AUDIT.md`.
